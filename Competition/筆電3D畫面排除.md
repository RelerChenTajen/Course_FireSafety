# 筆電開 simulate0.html 只有一片黑：處理流程

simulate0.html（大巨蛋 VR 防災導覽）是 3D 頁面，需要兩樣東西，缺一樣畫面就會整片黑。通常不是螢幕設定的問題。

| 可能原因 | 說明 |
|---|---|
| 3D 引擎沒有載入 | 舊版從網路（aframe.io）即時下載 3D 引擎，沒有網路或網路擋掉就載入失敗 |
| 瀏覽器的 3D 繪圖功能（WebGL）沒有開啟 | 關閉了「硬體加速」、開了省電模式，或顯示卡驅動被瀏覽器停用 |

2026/11/18 起，3D 引擎已放進專案的 `lib/aframe-1.6.0.min.js`，沒有網路也能開；無法顯示 3D 時，頁面會直接說明原因與處理步驟。

## 步驟 1：更新檔案

- 從 GitHub 下載最新版：<https://github.com/RelerChenTajen/Course_FireSafety>，或把整個平台資料夾重新複製到筆電。
- **`lib` 資料夾要一起帶**，而且要和 simulate0.html 放在同一層：

```
平台資料夾/
├─ simulate0.html
├─ platform.css
└─ lib/
   └─ aframe-1.6.0.min.js
```

## 步驟 2：重新開啟 simulate0.html，看畫面

| 看到的畫面 | 代表 | 怎麼做 |
|---|---|---|
| 正常顯示 3D 場景 | 原因是網路，已解決 | 不用再做什麼 |
| 「這台電腦目前無法顯示 3D 畫面」（3D 繪圖功能） | 瀏覽器的 3D 繪圖沒開 | 做步驟 3 |
| 「這台電腦目前無法顯示 3D 畫面」（3D 引擎沒有載入成功） | `lib` 資料夾沒帶到 | 回步驟 1，確認 `lib` 資料夾位置正確；或讓筆電連上網路再重新載入 |
| 仍然整片黑、也沒有說明 | 開到的是舊版檔案 | 回步驟 1 重新複製，再按 Ctrl + F5 |

## 步驟 3：開啟硬體加速

| 瀏覽器 | 在網址列輸入 | 要打開的選項 |
|---|---|---|
| Chrome | `chrome://settings/system` | 「使用圖形加速功能（如果可用）」，再按「重新啟動」 |
| Edge | `edge://settings/system` | 「可用時使用圖形加速」，再按「重新啟動」 |

做完後回到 simulate0.html，按頁面上的「🔄 改好了，重新載入」。

## 步驟 4：還是不行

1. 筆電**插上電源**，並關閉 Windows 的**省電模式**（部分筆電省電時會停用獨立顯示卡）。
2. 在網址列輸入 `chrome://gpu`（Edge 用 `edge://gpu`），看「WebGL」那一行：
   - 顯示 **Hardware accelerated**：3D 繪圖正常，請重新載入頁面。
   - 顯示 **Disabled** 或 **Software only**：更新顯示卡驅動程式，或換一台電腦。
3. 可以到 <https://get.webgl.org/> 測試，看得到旋轉的方塊就代表 3D 繪圖正常。

## 備案

- 換另一台筆電，或改用**手機**開啟（手機瀏覽器幾乎都支援 3D 繪圖）。
- 其他模擬頁（疏散動線、人群模擬、AIoT、醫院、倉儲、問答轉盤）不需要 3D，可以照常展示。
